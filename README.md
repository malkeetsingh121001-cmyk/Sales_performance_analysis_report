# Sales Performance Analytics

## Overview

This project analyzes sales data using Excel, Python,
and Power BI.

## Tools Used

- Microsoft Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- DAX

## Project Workflow

Raw Data
   ↓
Excel Data Cleaning
   ↓
Python Analysis
   ↓
Processed Dataset
   ↓
Power BI Dashboard

## Key Analysis

- Total Revenue
- Average Order Value
- Sales by Category
- Sales by City
- Top Products
- Salesperson Performance
- Monthly Sales Trends
